# Task Management System

## Project Overview

Task Management System is a web-based application developed using Java, Spring Boot, Thymeleaf, MySQL, Bootstrap, and Chart.js. The application helps users manage tasks efficiently by allowing them to create, update, delete, search, and filter tasks while providing dashboard statistics and graphical reports.

## Features

* User Registration
* User Login & Logout
* Session-Based Authentication
* Add New Tasks
* Edit Existing Tasks
* Delete Tasks
* Search Tasks by Title
* Filter Tasks by Status
* Dashboard Statistics
* Recent Tasks Section
* Task Status Analytics Chart
* Responsive User Interface
* MySQL Database Integration
